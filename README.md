# Predictive Maintenance

A machine learning project that predicts industrial machine failures using the
[Predictive Maintenance Dataset (AI4I 2020)](https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020).

## How it works

1. **Preprocessing** (`notebooks/Predictive_Maintenance_Preprocessing.ipynb`) — loads the raw
   dataset, builds the failure-type target from the raw failure-mode flags, cleans and encodes
   the data, scales it, balances the classes, and saves the processed train/test files plus the
   fitted scaler.
2. **Modeling** (`notebooks/Predictive_Maintenance_Modeling.ipynb`) — loads the processed files
   only (no raw data, no re-preprocessing), trains and compares five models, and saves the
   best one.
3. **Deployment** (`app.py`) — a Streamlit app where you enter machine readings, get a
   prediction of the failure type, and get an AI-generated maintenance recommendation.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Download the dataset from Kaggle and place `ai4i2020.csv` in `data/raw/`.
3. Run the notebooks in order (from inside `notebooks/`):
   - `Predictive_Maintenance_Preprocessing.ipynb`
   - `Predictive_Maintenance_Modeling.ipynb`

   This produces the processed CSVs in `data/processed/` and the trained model files in
   `models/`.
4. Set an API key for the LLM recommendation step:
   ```
   export ANTHROPIC_API_KEY=your_key_here
   ```
   To use OpenAI instead:
   ```
   export LLM_PROVIDER=openai
   export OPENAI_API_KEY=your_key_here
   ```
5. Run the app:
   ```
   streamlit run app.py
   ```

## Model

The target combines the five raw failure-mode flags (`TWF`, `HDF`, `PWF`, `OSF`, `RNF`) into
one multi-class label: `No Failure`, one of the five specific failure types, or
`Multiple Failures` when more than one flag fires at once.

Five models are compared — Logistic Regression, Random Forest, XGBoost, LightGBM, and
CatBoost — on accuracy, precision, recall, and F1 score. The best one is picked automatically
and saved for deployment.
